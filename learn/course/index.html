Understand every service — then explain it yourself

A hands-on course built from the real Expense Tracker: the actual handler.py, ocr.py, template.yaml and live infrastructure. Each module teaches one part, shows an interactive diagram, then quizzes you with hard questions — how we used it, why we chose it, what the alternatives were, and what we'd change.

How each module works

  1. Learn — the mental model, the why, the trade-offs and the failure modes.
  2. See — an interactive diagram: step through a real request, or click a service.
  3. Quiz — 10–15 deep questions. Reveal the model answer, grade yourself honestly; your score is saved in this browser.

Progress is stored locally — nothing is sent anywhere.
